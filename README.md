# 하루점 · 최종 개발 검증본

생년월일시를 바탕으로 오늘의 점수, 최근 3일 흐름, 4개 분야 문장, 주의 포인트를 제공하는 정적 웹서비스입니다.

## 바로 실행

공개용 통합 파일은 `dist/harujeom.html`입니다. CSS,JavaScript,manseryeok 데이터와 MIT 고지가 모두 포함됩니다. 브라우저로 열도록 제작했으며 설치·서버·CDN이 필요 없는 구조입니다. **이 작업 환경의 브라우저 도구는 file://를 차단하므로 실제 더블클릭·오프라인 실행은 사용자 확인이 필요합니다.** HTTP 실행과 외부 실행 의존성 검사는 통과했습니다.

개발용 실행은 `npm start` 후 `http://localhost:4173`에서 확인합니다. 이 주소는 로컬 전용이며 공개 배포 주소가 아닙니다. `dist/index.html`은 CSS/JS와 함께 사용하는 개발용 화면입니다.

## 수정 / 빌드 / 검증

Node.js 18 이상. 아래 명령을 프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run build
npm test
node scripts/check-artifact.mjs
```

학교 제출용 사본은 개인정보가 없는 예시 경로를 바꾸어 생성할 수 있습니다. 파일명은 공개 스크립트에 넣지 않고 인자로 전달합니다.

```sh
npm run build -- --submission submission/my-final.html
node scripts/check-artifact.mjs submission/my-final.html
```

`submission/`은 Git에서 제외됩니다. 공개본과 제출본은 같은 빌드의 바이트 동일 사본입니다. HTML 하나를 다른 폴더로 옮겨 실행하는 검증 절차는 [수동 체크리스트](manual-test-checklist.md)를 따릅니다.

## 구조와 기술

- `src/fortune.js`: 만세력 호출,프로필/날짜 검증,점수 계산
- `src/messages.js`: 분야60,총운15,흐름15,주의20개 문장 및 결정적 선택
- `src/profile.js`: 입력 변환,저장소 예외,자정 갱신 조건
- `src/app.js`: 입력/결과 화면,예시 분리,저장·삭제·갱신 연결
- `dist/index.html`, `dist/style.css`, `dist/app.js`: 개발용 정적 화면
- `dist/harujeom.html`: 공개용 통합 파일
- `scripts/`: 빌드·아티팩트 검사·저장제한 QA fixture 생성
- `tests/`: 원본14개와 추가22개 회귀 테스트,수정 전 점수 fixture
- `docs/validation/`, `screenshots/`: 기준·검증 기록 및 가상정보 화면

HTML/CSS/JavaScript,manseryeok 2.0.0,esbuild 0.25.12. 프레임워크/서버 DB/로그인 없이 동작합니다. 소스 변경 후에는 반드시 다시 빌드합니다.

## 계산 규칙 v0.1
manseryeok 2.0.0(MIT)으로 양음력 변환과 간지를 계산합니다. 한국 날짜 기준, 일자 경계는 자정, 출생지 진태양시 보정은 미적용입니다. 출생 연도는 1900년부터 올해까지이며 라이브러리 지원 상한(양력 2300년, 음력 2100년)도 적용합니다. 미래 생일은 차단합니다. 일진 계산 지원 범위는 1800년부터 2300년입니다.
오행 순서는 목→화→토→금→수. 입력 오행에서 대상 오행까지 순환 거리 0부터 4까지에 가중치 [8,5,-6,-9,10]을 부여합니다. 출생 각 기둥의 천간/지지와 오늘 일진 천간/지지 관계 가중치의 평균을 구하고 `기준점=65+평균×2`로 계산합니다. 분야별 목표 오행과 출생 일간의 관계 가중치를 기준점에 더해 반올림 후 0점부터 100점 사이로 제한합니다. 금전/연애/일·공부/대인 분야의 목표는 각각 오늘 일간+2, 오늘 일지+1, 오늘 일간, 오늘 일지의 순환 오행입니다. 총운은 4개 분야 점수의 평균을 반올림합니다.
80 이상/60 이상/60 미만의 3구간으로 분야 문장을 선택하고 최저 점수 분야의 주의 문장을 표시합니다. 동점이면 금전→연애→일·공부→대인 순서입니다. 흐름 문장은 오늘−그제 점수 차가 +6 이상/-6 이하/그 외인지로 선택합니다.
출생시간 미상은 계산용 정오로 라이브러리를 호출하되 시주를 점수 및 화면에서 제외합니다. 성별은 저장만 하고 점수에는 사용하지 않습니다.
이 규칙은 제작자가 정의한 오락용 지표이며 전통 명리학의 공식 점수나 과학적 예측이 아닙니다. 서비스에서 생성형 AI API를 호출하지 않습니다.

## 문장 규칙 1.0 · v0.1 대비 개선

점수 산식은 그대로 유지했습니다. 문장만 별도 버전으로 관리합니다. 정규화한 양력 생일과 시간(미상은 별도 표시),문장 채널 해시와 날짜 일련번호로 5개 중 하나를 선택합니다. 같은 사용자·날짜에는 동일하며 양력/음력 동등 입력과 성별은 문장을 바꾸지 않습니다. 인접 날짜의 같은 분야 문장 반복을 방지합니다. 새로고침 무작위 선택을 사용하지 않습니다.

필수값 안내,저장 실패 대응,예시/개인 정보 분리,모바일 글자·버튼·대비·포커스를 개선했습니다. 그래프는 최근3일만 계산하며 내일은?로 표시합니다. 구체적인 기획 대비 차이는 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

## 데이터와 개인정보

브라우저 localStorage 키 `harujeom.profile.v1`과 기존 JSON 형식을 유지합니다. 기본은 저장하지 않으며,선택한 경우에만 생년월일·시간·달력·윤달·성별을 이 브라우저에 저장합니다. 저장 해제 및 삭제가 가능합니다. 저장이 차단되면 이번 방문의 메모리로 계산합니다. 삭제 실패 시 성공했다고 표시하지 않고 브라우저 설정의 사이트 데이터 삭제를 안내합니다. 예시는 실제 프로필을 덮어쓰지 않습니다.

입력값은 외부로 전송하지 않습니다. 일반 호스팅 접속 로그는 별개이며 회원가입·기기간 동기화는 없습니다. 파일 경로/브라우저마다 저장소가 다를 수 있습니다. 학교 제출 파일과 개인정보가 있는 원본 문서를 공개 저장소나 웹 루트에 넣지 마세요.
