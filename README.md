# 하루점 · 중간 제출 v0.1

생년월일시를 바탕으로 오늘의 점수, 최근 3일 흐름, 4개 분야 문장, 주의 포인트를 제공하는 정적 웹서비스입니다.

## 바로 실행
- `dist/index.html`을 브라우저로 여세요. HTML/CSS/번들 JS가 포함되어 빌드 없이 실행할 수 있습니다.
- 저장 기능을 안정적으로 시연하려면 프로젝트 폴더에서 `python3 -m http.server 4173 --directory dist` 실행 후 `http://localhost:4173`에 접속하세요.
- file://에서 localStorage 지원 여부는 브라우저에 따라 다릅니다. 저장 불가 시 이번 방문에서만 결과를 보여줍니다.
- 첫 화면의 ‘입력 전에 예시 먼저 보기’를 누르면 가상 데이터로 체험할 수 있습니다.

## 수정 / 검증
Node.js 18 이상 필요. `npm ci`, `npm test`, `npm run build` 순서로 실행합니다.
`src/fortune.js`는 계산·검증, `src/app.js`는 화면·저장, `dist/style.css`는 디자인, `dist/index.html`은 화면 구조입니다. JS를 수정하면 빌드를 다시 실행해야 합니다.

## 계산 규칙 v0.1
manseryeok 2.0.0(MIT)으로 양음력 변환과 간지를 계산합니다. 한국 날짜 기준, 일자 경계는 자정, 출생지 진태양시 보정은 미적용입니다. 출생 연도는 1900년부터 올해까지, 미래 생일은 차단합니다.
오행 순서는 목→화→토→금→수. 입력 오행에서 대상 오행까지 순환 거리 0~4에 가중치 [8,5,-6,-9,10]을 부여합니다. 출생 각 기둥의 천간/지지와 오늘 일진 천간/지지 관계 가중치의 평균을 구하고 `기준점=65+평균×2`로 계산합니다. 분야별 목표 오행과 출생 일간의 관계 가중치를 기준점에 더해 반올림 후 0~100으로 제한합니다. 금전/연애/일·공부/대인 분야의 목표는 각각 오늘 일간+2, 오늘 일지+1, 오늘 일간, 오늘 일지의 순환 오행입니다. 총운은 4개 분야 점수의 평균을 반올림합니다.
80 이상/60 이상/60 미만의 3구간으로 분야 문장을 선택하고 최저 점수 분야의 주의 문장을 표시합니다. 동점이면 금전→연애→일·공부→대인 순서입니다. 흐름 문장은 오늘−그제 점수 차가 +6 이상/-6 이하/그 외인지로 선택합니다.
출생시간 미상은 계산용 정오로 라이브러리를 호출하되 시주를 점수 및 화면에서 제외합니다. 성별은 저장만 하고 점수에는 사용하지 않습니다.
이 규칙은 제작자가 정의한 오락용 지표이며 전통 명리학의 공식 점수나 과학적 예측이 아닙니다. 서비스에서 생성형 AI API를 호출하지 않습니다.

## 데이터
브라우저 localStorage 키 `harujeom.profile.v1`. 저장 선택 해제 및 삭제 가능. 생년월일 등 입력은 서버로 전송하지 않습니다. 일반 웹 호스팅 접속 로그는 별개입니다. 회원가입·서버 DB·기기간 동기화는 없습니다.

## 검증 / 남은 작업
자동 테스트 14개 통과. 실제 IAB 브라우저에서 입력, 재접속, 수정, 날짜 오류 안내, 삭제 후 재접속, 예시 모드를 확인했습니다. 390px 모바일 뷰포트에서 가로 넘침이 없음을 확인했습니다. 실물 iOS/Android·타 브라우저, 광범위한 절기 경계의 독립 대조, 사용자 만족도 검증은 최종 제출 전 과제입니다.
